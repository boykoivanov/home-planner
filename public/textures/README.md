# Tile textures

Put one image per tile here, cropped to a single tile face, seen straight on.
The planner loads them automatically and uses them instead of the colour preview.

| Tile        | File name        | Real size        |
| ----------- | ---------------- | ---------------- |
| Wall main   | wall-main.jpg    | 60 × 29.7 cm     |
| Wall decor  | wall-decor.jpg   | 60 × 29.7 cm     |
| Floor       | floor.jpg        | 59.8 × 18.5 cm   |
| Floor decor | floor-decor.jpg  | 59.8 × 59.8 cm   |

Face variations: add wall-main-2.jpg, wall-main-3.jpg … and the planner mixes them.
.png and .webp also work. Reload the page after adding files.
